# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in VanUikit, please report it
privately. **Do not open a public issue for security-sensitive reports.**

Preferred options:

1. Use **GitHub Private Vulnerability Reporting** for this repository if it is
   enabled (Security tab → "Report a vulnerability").
2. If private reporting is not available, open a minimal public issue asking to
   establish a private channel **without** including exploit details, proof-of
   concept, or sensitive information. A maintainer will follow up.

Please include, when possible:

- A description of the issue and its potential impact
- Affected versions or components
- Steps to reproduce or a minimal proof of concept (shared privately)
- Any suggested mitigation

## Scope

This policy covers the code in this repository, including the `vanuikit`
library, server helpers, demo, and documentation site sources. Third-party
dependencies should be reported to their respective maintainers when the issue
is not caused by VanUikit's usage.

## Response

Maintainers will acknowledge reports, assess impact, and work on a fix or
mitigation. Timelines may vary depending on severity and maintainer
availability. We appreciate responsible disclosure and will credit reporters
when appropriate and desired.
